# Coffee Sales Dashboard Excel Portfolio Project

An interactive sales dashboard built in Microsoft Excel to analyze coffee sales performance using dynamic visualizations, Pivot Tables, and advanced Excel functions.

---

## Project Overview

This project demonstrates how Microsoft Excel can be used as a powerful Business Intelligence tool to transform raw transactional data into meaningful insights. The dashboard integrates order, customer, and product datasets to analyze sales performance, customer behavior, and regional trends through interactive reports.

---

## Objectives

- Analyze overall coffee sales performance
- Identify top-performing customers
- Compare sales across different countries
- Track monthly sales trends
- Evaluate coffee type performance
- Create an interactive dashboard for business decision-making

---

##  Dataset

The project uses three related datasets:

### Orders
Contains transactional information including:
- Order ID
- Order Date
- Customer ID
- Product ID
- Quantity
- Sales

### Customers
Contains customer information including:
- Customer Name
- Country
- Email
- Loyalty Card Status

### Products
Contains product information including:
- Coffee Type
- Roast Type
- Package Size
- Unit Price
- Profit
